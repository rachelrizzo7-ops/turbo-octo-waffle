## When an item sells

Swap the file for the next piece and update its name, price, and alt text in `index.html` — search for the old filename to find the right spot. The filenames above are just today's placeholders; rename them (and update the matching `src=` in the HTML) to whatever makes sense for what's actually on the floor.
